# 001 — codepy scaffold handoff

## What this repo is

A personal Python "code playground" (`codepy`). Not a library, not a monorepo,
not production code. See `README.md` and `docs/readme.md` (the source design
doc — do not edit it).

## Decisions already made

- Repo treated as **public** → MIT `LICENSE` (copyright placeholder `<you>`).
- **Single root virtualenv** (`.venv/`). Per-subproject `pyproject.toml` allowed
  later but not scaffolded yet.
- Root `pyproject.toml` carries **dev tooling only** (ruff, pytest, mypy config).
- `requirements.txt` is **runtime deps** (`pip`, `openpyxl`, `et_xmlfile`) and is
  kept as-is.
- `requirements-dev.txt` is **tooling** (`ruff`, `pytest`, `mypy`, `pre-commit`).
- `07-playground/`, `06-experiments/`, `archive/` are excluded from ruff and mypy.

## Files that exist (verified)

Root:
- `README.md` — codepy README (from the template in `docs/readme.md`, with
  "Running things", "Secrets", and "What this is not" content folded in).
- `LICENSE` — MIT, `Copyright (c) 2025 <you>`.
- `Makefile` — targets: `help`, `activate`, `setup`, `lint`, `format`, `test`,
  `run`, `clean`. `.PHONY` includes all of them.
- `pyproject.toml` — dev-tooling config only (ruff/pytest/mypy).
- `requirements.txt` — runtime deps.
- `requirements-dev.txt` — dev deps.
- `run.py` — central dispatcher. Loads targets by **file path** via
  `importlib.util.spec_from_file_location`, so digit-prefixed folders work.
  `TARGETS` maps a name to `"path/to/file.py:function"`. `main(argv)` lists
  targets when called with no args, otherwise dispatches.
- `.editorconfig`, `.env.example`, `.gitignore`, `.pre-commit-config.yaml`.
- `.github/workflows/ci.yml` — runs `make lint` and `make test` on push/PR.
- `docs/readme.md` — source design doc (do not edit).

Templates:
- `templates/experiment/NOTES.md`
- `templates/experiment/pyproject.toml`

## Known issues / next steps

### 1. `TARGETS` in `run.py` is empty

`make run` / `python run.py` prints "no targets configured yet". Needs at least
one entry plus a placeholder target module, e.g.
`02-scripts/file-tools/rename_bulk.py` with `main(args) -> int`, registered as
`"02-scripts/file-tools/rename_bulk.py:main"`.

### 2. Directory tree not scaffolded

These directories do **not** exist yet and need to be created, each with a
`.gitkeep`:

```
01-foundations/{data-structures,algorithms,patterns,python-idioms}/
02-scripts/{automation,file-tools,cli}/
03-web/{fastapi,flask,async-servers}/
04-databases/{sql,nosql,orms,migrations}/
05-networking/{sockets,http-clients,protocol-experiments}/
06-experiments/
07-playground/
docs/{notes,cheatsheets}/
archive/
```

For each **top-level** folder (`01-foundations/` … `07-playground/`, `docs/`,
`templates/`, `archive/`), also add a one-line `README.md`:

```
# <folder-name>

See the root README for purpose and conventions.
```

### 3. `templates/experiment/README.md` missing

Create it with sections: Question / What I tried / What I learned / Next time.

### 4. Minor: `Makefile` `activate` target

`activate:` exists and is in `.PHONY`, but it cannot affect the parent shell
(each recipe line runs in its own shell). Either remove it or leave it as a
no-op reminder. Not urgent.

## How to verify after changes

```bash
make help          # lists targets
make lint          # ruff + mypy (mypy skipped if no .py files)
make test          # pytest; exit 5 = no tests collected, treated as success
make run           # lists configured targets
python run.py      # same as make run
```

## How to resume in a new session

1. Start aider in the repo root.
2. Add these files to the chat: `README.md`, `Makefile`, `run.py`,
   `pyproject.toml`, `requirements.txt`, `requirements-dev.txt`,
   `.gitignore`, `docs/readme.md`, and this file.
3. Say: "Continue codepy scaffold. See `docs/history/001.md`. Next: add a
   placeholder target and register it in `TARGETS` (issue 1), scaffold the
   directory tree (issue 2), and create `templates/experiment/README.md`
   (issue 3)."

## Conventions (from README)

- Python 3.11+; `ruff format` + `ruff check`; `pytest`; `mypy`.
- Tests live next to code as `test_*.py`.
- Commits: Conventional Commits (`feat:`, `fix:`, `exp:`, `docs:`).
- Experiment folders: `YYYY-MM-DD-topic`.
- Retire untouched code to `archive/` after ~12 months.
- Secrets go in `.env` (gitignored); copy `.env.example` to start.
